# 界面信息架构与层级规范（UX / IA）

> **本文档是 Web 与 iOS 两组共同遵守的界面逻辑基准。** 核心思想：**界面层级 = 产品哲学** —— 以"人"为优先，AI 辅助不越位，处处可待定。

---

## 0. 设计哲学 → 界面映射

| 产品哲学 | 界面落地 |
|----------|----------|
| 人主导，AI 参谋 | 导航以"我"为第一位，AI 在末位且受邀才出现 |
| AI 辅助不越位 | AI 界面**没有任何"保存/确定"按钮**，只给建议 |
| 处处可待定 | 待定是**可见的第三态**，非禁用灰 |
| 决策权在人 | 所有改变状态的按钮只在"我的世界"平面出现 |
| 透明可溯源 | 每条建议必显示"为什么" |

---

## 1. 三层代理模型（组织主线）

```
┌─────────────────────────────────────────────────────┐
│  第一平面 · 我的世界（用户主导）        —— 顶层、常驻      │
│    我 · 今日                                          │
│    ↓ 这里发生"写"（编辑、标记、确认）                    │
├─────────────────────────────────────────────────────┤
│  第二平面 · 决策与行动（用户专属）       —— 藏在第一平面内   │
│    编辑路径、改状态、采纳/拒绝                          │
│    ⛔ AI 永不进入此平面（无"写"权限）                    │
├─────────────────────────────────────────────────────┤
│  第三平面 · AI 参谋（只读建议）        —— 邀请制、侧翼      │
│    对话 + 建议 + "为什么" + 选项                        │
│    ✔ 只有"建议"与"可拒绝"，没有"保存/确定"              │
└─────────────────────────────────────────────────────┘
```

---

## 2. iOS 主导航（3 Tab，以"我"为第一）

```
┌──────────────────────────────────────────┐
│  我(默认)       今日        参谋            │   ← 底部 3 Tab
│  (个人核心)     (当日行动)   (受邀顾问)      │
└──────────────────────────────────────────┘
```

### Tab 1 · 我（默认落点）
- 顶部：个人档案头（姓名/年级）+ **兴趣板块 chips** + ⚙️设置（右上角，不占 tab）
- 中段分段控制：`路径 | 成长`
  - **路径**：人生路径树（愿景 → 长期 → 短期 → 任务），节点状态徽章 `进行中 / 已达成 / 待定 / 已放弃`，每节点可"问 AI"
  - **成长**：个人成长账本 —— 过程性评价、成绩、趋势图（按课程/维度聚合）
- 底部浮动：`问 AI`（上下文=当前节点/当前目标）

### Tab 2 · 今日
- 时间轴（课表 + 专注窗口 + 今日任务），可切 日/周
- 当日目标条（从路径拉取，若"待定"如实显示）
- 专注模式从这里进入（全屏覆盖，可退出）

### Tab 3 · 参谋
- 对话流 + 建议卡（每卡带"为什么"）
- **无"保存/确定"按钮**；"采纳"跳回 Tab1 编辑器，由用户亲手落地
- 顶部常驻："我是参谋，决定权在你"

## 3. Web 布局（侧栏 + AI 抽屉）

```
┌──────────────┬──────────────────────────────┬──────────┐
│  左侧栏       │  主内容区                     │ 右侧 AI    │
│  · 我         │  · 卡片式 Dashboard           │  参谋面板   │
│  · 今日       │  · 路径树 / 甘特               │  (可召唤)   │
│  · 参谋       │  · 图表(成绩趋势/评价雷达)       │  滚动对话   │
│  · 设置       │  · 表格 / 详情                 │  建议卡    │
└──────────────┴──────────────────────────────┴──────────┘
```
- AI 参谋是**右侧抽屉**（侧翼顾问），不占主导航。
- 主区永远展示用户自己的世界。

---

## 4. 关键交互流程

### 4.1 共创人生路径
```
用户选兴趣 + 写人生想法
  → 「我」生成路径草案(含"待定"占位)
  → 用户点节点"问 AI" → 召唤参谋(上下文=该节点)
  → AI 给建议稿(新增/改写/利弊)
  → 用户【采纳】→ 跳回「我」的编辑器
  → 用户亲手确认 → 落地(来源:user)
  → 用户【拒绝】/【标记待定】→ 不变更
```

### 4.2 今日 → 课表 → 专注
```
「今日」时间轴显示课表与专注窗口
  → 用户点专注窗口 → 进入专注(全屏，可退出)
  → 专注结束 → 反馈写入「成长」
```

### 4.3 AI 个性化辅导
```
用户进「参谋」或点"问 AI"
  → AI 读取(路径+评价+成绩+近期日程)
  → 给建议卡，每条附"为什么"，并有"采纳/暂缓/拒绝"
  → 采纳才落地(写)；其余只留在对话
```

---

## 5. 界面层级硬规矩（写出即规范）

1. **AI 无写权限铁律**：AI 所在界面不出现"保存/确定/完成"，只有"建议"与"去编辑"。
2. **待定三态可视化**：`进行中 / 已达成 / 待定 / 已放弃` 全部明确渲染，不隐藏、不灰化禁用。
3. **建议必带依据**：每条建议下显示"为什么这么建议"，用户可质疑。
4. **决策入口属于用户**：所有改变状态的按钮只在"我的世界"平面。
5. **AI 是侧翼，不是封面**：任何页面 AI 不做首屏主角（抽屉 / 受邀房间）。

---

## 6. iOS 与 Web 差异

| 维度 | iOS | Web |
|------|-----|-----|
| 主导航 | 底部 3 Tab | 左侧栏（常驻，可折叠） |
| AI 入口 | Tab + 浮动"问AI" | 右侧抽屉 + 独立页 |
| 专注 | 全屏覆盖 + 锁屏/快捷指令 | 页面级 + 通知降噪 |
| 信息密度 | 单列、卡片、时间轴 | 双列、图表、表格 |

---

## 7. 开放平衡点

- **默认落点**：推荐 Tab1「我」（人优先）；若想"打开就看今天"，默认设为 Tab2 而「我」仍在第一位。
- **成长/路径分合**：当前并入「我」；若需更显眼，可拆为 4 Tab（我/今日/成长/参谋），但"功能感"会略重。
